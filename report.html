huggingface.co/reflection/Beam-1.0-501B-A23B · Apache-2.0 · 501B MoE / 23B active

§0五条核心发现

1

真开源，不是"开放权重"话术

Apache-2.0（HF API tags 实测），模型卡明确列出不禁止蒸馏、用输出训练其他模型、微调、量化、合并——比 Llama 系社区许可证干净一个量级。这是"能拥有"的模型，不是"能调用"的模型。

2

501B 存、23B 醒

稀疏 MoE，256 个 expert，每 token 只激活 23.4B。推理算力跟 23B 走，显存跟 501B 走（FP8 约 500GB，NVFP4 约 250GB）。多 GPU 服务器模型，不是工作站模型——真正的个人可用要等社区蒸馏版。

3

第一卖点是"省 token"，不是跑分

同等解题质量下推理 token 约为领先开放模型的 1/3。agent 场景里 multi-step 任务的推理 token 是成本大头——这不是跑分，是账单。MCP Atlas 80.8%、Terminal Bench 80.1%，为 agentic coding 而生。

4

公司：前 DeepMind + Nvidia 重注

2024 年成立，创始人 Misha Laskin（Gemini reward modeling）与 Ioannis Antonoglou（AlphaGo 联创）。Nvidia 领投 $800M，2026-04 融资估值 $25B pre-money。FT 爆料 Nvidia 谈加码或收购——早期阶段，未证实。

5

训练数字全是公司口径

23.8T tokens、10,500 × GB300 四周 RL、1 亿+ rollouts、92.3% goodput——技术报告标注 "coming"，独立评测 pending。"3–4x 更少推理算力"是估算不是实测美元成本，发布前先复现再信。

大判断：Beam 的赌注是"效率"而非"峰值"——不跟 Kimi K3 拼 raw 分，而是把"同等智能、更少算力"做成可验证的成本优势。开放权重榜单长期被中系模型统治，Beam 是第一款有资格上桌的 Apache-2.0 大模型。

§5安全与对齐

  • 一手三层评估：Open Safety Framework、自家 Iris Safety Evaluations（ISE，将开源的评测套件，覆盖单轮/多轮/越狱/agent）、外部第三方 assurance。
  • 一手ISE 数字：有害请求拒绝/转向率 88.9–89.7%，无害请求合规率 81.5–82.1%。详细方法与结果见安全报告 reflection.ai/beam-safety-report。
  • 一手上报通道：reports@reflection.ai；另有 Usage Policy 列出建议审查的使用领域。

§6k2 视角：为什么做 agent runtime 的人该盯着它

23B active = 推理账单小

  • MoE 稀疏激活，per-token 算力只跟 23B 走
  • 自建 agent 集群时，推理成本按激活参数算，不按 501B

不禁蒸馏 = 可拥有的底座

  • 能微调、量化、蒸馏、合并——"把模型变成自家 plumbing"的前提
  • DeepSeek 时代是"便宜的 API"，Beam 给的是"便宜的自有"

为 agent loop 优化

  • 省约 3x 推理 token：multi-step 任务的成本杀手
  • MCP 原生 + terminal 强，HLE 带工具 +15 个点

部署现实

  • 250–500GB 仍是服务器级，不是工作站模型
  • 先拿云上版本跑评测，再决定要不要自建；等社区蒸馏版

§?未核实 / 开放问题

  • 技术报告——标注 "coming"，训练细节（数据配比、RL 算法）以报告为准，在此之前训练规模数字均为公司口径。
  • 独立评测——全部基准为官方自测，LMArena、人工 blind test 中的真实排位 pending。
  • DFlash2 变体——HF 上有 -DFlash2 仓库，模型卡未解释其含义与推荐用途。
  • Nvidia 收购/加码——FT 爆料的早期谈判，双方未评论。
  • 中文能力——官方称"主要为英文开发"，中文基准未披露。
  • 蒸馏条款边界——模型卡称不禁止，但"用输出训练其他模型"的法律边界仍以律师意见为准。
